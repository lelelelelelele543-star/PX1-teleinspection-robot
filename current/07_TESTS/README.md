# 07 TESTS

No engineering PASS is granted by CAD export alone.

Required test ladder:
- A0 drivetrain no-load/load run;
- A1 straight/reverse/turn and DN150 physical fit;
- A2 40 m tether loaded voltage + communication test;
- A3 video/light/lift-cycle test with traction motors running;
- A4 integrated demonstration run;
- A5 pressure decay/submersion, thermal and endurance tests.

Record actual measured values, failures and fixes. A failed test changes the design only as much as needed to remove the verified failure.
