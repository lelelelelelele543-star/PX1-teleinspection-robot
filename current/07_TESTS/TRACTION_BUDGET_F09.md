## Выводы
1. Первый этап (40 м) обеспечен с запасом при любом состоянии трубы.
2. PX1 почти вдвое легче CRP150, сцепление пропорционально весу. Чтобы повторить поведение
   Proteus, массу нужно довести до ~9 кг (балласт в нижней части корпуса / более тяжёлые
   материалы корпуса). Mini-Cam сама продаёт утяжелитель 2,5 кг для CPL150S/CRP140 —
   значит, ограничение по сцеплению для них тоже рабочий вопрос.
3. Для 100–150 м нужен и вес, и больший момент: моторы GA24 дают 57 Н, а требуется ≥60–70 Н
   с запасом. Это вопрос выбора мотора (H05), каркас привода не меняется.
4. Скорость 5,9 м/мин низкая для инспекции (обычно 10–12 м/мин у краулеров DN150); скорость
   Proteus в открытых источниках не найдена.
