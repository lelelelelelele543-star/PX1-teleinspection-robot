## Обоснование
- Предел DERIVED: r ≤ √((75−3)² − (54.5+y)²) − (51.524266−45) → 29.22 @ y8, 21.08 @ y12.
- Выбранные значения 28.5 / 20.5 — ESTIMATED (запас ~0.7 мм к пределу), не заводской
  профиль QRW90SR/150. Точного профиля шины в источниках нет: на Диске только
  ASS-003-142 Wheel Lock Assy.
- Глухая проверка: максимум расстояния на прямом отрезке меридиана — в вершине,
  поэтому проверка вершин ограничивает всю поверхность вращения.
- Посадочное гнездо фиксатора (r10.2) и шайба r10 остаются внутри обода (r ≥ 20.5).
