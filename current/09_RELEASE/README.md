# 09 RELEASE

This folder is the gate to fabrication/production, not a dumping ground for experimental CAD.

A6 release requires:
- proven 6×6 crawler geometry;
- exact bought-part articles and measured/official envelopes;
- no critical machining dimension marked HOLD;
- released STEP/STL and part drawings;
- released BOM;
- electrical pinout and wiring;
- firmware version/protocol reference;
- assembly/disassembly procedure;
- sealing procedure;
- test acceptance sheet.

Until these conditions are met, project status remains prototype/HOLD.
