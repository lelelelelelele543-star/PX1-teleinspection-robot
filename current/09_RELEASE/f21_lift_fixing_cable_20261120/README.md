# F21 — крепление основания лифта 4×M4 и трасса кабеля камеры по лифту — 2026-11-20

Инженерный прототип, НЕ выпуск. Закрывает два пункта «Не решено» из F18: крепление основания FAL-002-067 к крышке L01
и укладку кабеля LAPP 0028679 при подъёме лифта 0…69°. Наружный корпус и крышка не менялись (только глухие резьбы
сверху крышки). Чертежи остаются на Google Диске.

## 1. Крепёж основания по DRW-002-744
Спецификация 744: поз. 14 FIX-000-598 «M4 X 12 SKT CAPHEAD A2» ×4 (CONFIRMED) → ISO 4762 M4×12 A2.
(Поз. 9 FIX-000-637 M4×8 button ×2 крепят пластину рычага FSS-002-073, не основание.)

Шаг снят с векторной геометрии PDF (вид сверху + разрез A-A, 1:1,5). Масштаб перепроверен по трём деталям:
резьбовой хвостовик M4 = 4,00 мм, шестигранник головки s3 = 2,95 мм, гайка M10 = 17,0 мм (как в F18).

Укорачивать винты не пришлось: M4×12 по спецификации проходит в крышку 7 мм.
Зазоры резьбы M4: до канавки уплотнения 1,05 мм (вбок, резьба к тому же выше канавки); до резьб M3 Cincon ≥45 мм;
до ввода M12 и клапана 12,95 мм; до винтов крышки X284 29,3 мм. Головки: до гайки M10 2,1 мм, до рычага зажима 3,9 мм.

## 2. Кабель камеры по лифту
Кабель LAPP UNITRONIC FD P plus A 0028679: OD 5,4, минимальный радиус по LAPP 5×D = 27 мм при движении,
3×D = 16,2 мм неподвижно (CONFIRMED, каталог LAPP).

Трасса (сложено, θ = 0), константа HARNESS_ROUTE в мастере, тело — сдвиг окружности по линиям и дугам:
1. Выход из SP13 X12 → подъём перед корпусом на X15 → дуга R17 → точка P (X32, Z116,8): зажим в пазу C-рычага
   корпуса лифта (неподвижно относительно камеры).
2. По пластине рычага Z116,8 (кабель лежит на пластине, верх Z113,9): открытая клипса 1 на X74, S-петля в плоскости
   пластины (4 дуги R27 по 53,7°, вбок на −22, X81,5…168,5), клипса 2 на X176. В клипсах кабель скользит.
3. S-изгиб R27 (17,6° вверх / 32,6° вниз, гребень Z119,3) над осью A → точка K (X259,4, Z118,4): начало печатной направляющей на вводе.
4. Направляющая: дуга R17 на 75° вниз → вертикально в Skintop M12 (верх Z102), конец трассы X272 Z96.

Проверка длины (tools/lift/check_lift_kinematics.py): нужная длина = неподвижные участки + кратчайший путь с R ≥ 27
от P до клипсы 1 + шаг клипс + кратчайший путь с R ≥ 27 от клипсы 2 до K (кривые Дубинса, препятствия не учтены —
нижняя оценка), θ = 0…69° с шагом 0,5°.

| Величина | Значение |
|---|---|
| Длина трассы в модели | 332,4 мм |
| Нужно при 0° | 318,0 мм |
| Нужно при 69° | 312,3 мм (подъём укорачивает путь на 5,7 мм) |
| Наибольший прирост нужной длины на 0…69° | 0 мм (максимум при 0°) |
| Запас (модель − нужно при 0°) | 14,4 мм, условие ≥ прирост + 10 → **PASS, резерв 4,4 мм** |
| Радиусы | подвижные участки 27,0 (=5×D); неподвижные R17 (≥16,2) |

Почему так: клипса 2 дальше X180 или направляющая с меньшим углом дают при 50…69° петлю на 150+ мм; вертикальный
ввод с верхом Z102 не позволяет повернуть на R27 под трубой DN150 — поэтому неподвижная направляющая R17.
Высота: верх кабеля Z122,0 (было 120,2); зазор до DN150 3,4 мм (по коробке тела с петлёй — внутри трубы).
