# F17 — догрузка PX1 к массе CRP150: балласт и ступицы колёс — 2026-11-19

Решение пользователя: догрузить до ~9 кг. Инженерный прототип, НЕ выпуск.

## Ступица колеса QRW90
По данным поиска (Mini-Cam ASS-004-496 вид, ролик Minicam «How to change wheels on the Proteus Crawler»,
каталог GAP): у колёс QRW металлическая ступица ≈0,5 D и литая шина; замок — поворотный некруглый упор под
винтом с шестигранником (ключ 4 мм), без пружин. В модели колесо разделено: алюминиевая ступица r≤22
(ESTIMATED) + резиновая шина. Масса колеса ≈0,125 кг (оценка поиска 0,18–0,25 кг — модель скорее занижает).

## Балласт
Свободный объём полости найден по габаритам всех деталей с запасом 1 мм и исключением зоны
вертикального извлечения моторов и сервисного окна. 5 блоков (≈94 см³), координаты в BALLAST_BOXES:
две стенки по бокам у носа (X25…90), плита под моторами (Z25…30), два блока в корме (X266…287).
Материал — **СТАЛЬ** (решение пользователя 2026-11-19). Сравнение вариантов:

| Балласт | Масса PX1 по модели | Сцепление слизь/мокро/чисто | 150 м кабеля |
|---|---|---|---|
| Сталь 7,85 | **7,1 кг** | 30 / 51 / 71 Н | только чистая труба |

Мотор — кандидат F16 (≈83 Н, 9,8 м/мин). До 9,25 кг CRP150 остаётся ≈1,2 кг даже с вольфрамом:
корпус PX1 полый под нашу электронику.

## Проверки
build 0 пересечений, извлечение моторов PASS, pipe PASS, integrated 19/19 PASS.

## Не решено
