# F27 — балласт: что можно и чего нельзя — 2026-11-21

Цели из гейта F26: масса 9,25 кг ±10 %, ЦТ не меньше 5 мм ниже оси трубы DN150, задняя ось ≥20 %.
Сейчас (F25): 7,92 кг, ЦТ ниже оси на 2,2 мм, оси 49/33/17 %.

## Главный вывод
**В стали цель по ЦТ недостижима.** Ориентир из F26 («+1,3 кг низко у кормы, X≈230 Z≈18») неверен:
низ кормы занят драйверами Pololu, муфтами, Z16/Z40 и бобышкой M8, свободного низкого объёма там нет.
Свободная полость (с запасом 0,5 мм и зоной вертикального извлечения моторов) — 242 см³, но она в основном
на средней высоте: если залить сталью всю, масса 9,08 кг, а ЦТ поднимется лишь до 2,6 мм ниже оси.

Единственный низкий и тяжёлый рычаг — наружная плита FSS-002-060 (Z11…23, самый низ краулера).

Все значения ESTIMATED: свободный объём по габаритам деталей (как в F17), блоки в реальности — параллелепипеды,
крепление, провода и тепло не учтены. Расчёт: `ballast_options.py` → `ballast_options.json`.

## Изменение базы (change-control, AGENTS.md)
- Что меняется: материал плиты FSS-002-060 (у Mini-Cam префикс FSS — нержавейка). Геометрия, выемка, 2×M8 — без изменений.
- Почему: при 2,2 мм ЦТ ниже оси восстанавливающий момент при крене 10° ≈0,03 Н·м (при 7,2 мм — ≈0,11 Н·м);
  краулер почти не сопротивляется закручиванию кабелем и наезду одного борта на отложения. Сталью внутри корпуса не исправляется (таблица).
- Герметичность: не затрагивается (плита снаружи). Обслуживание: то же. Изготовление: W-Ni-Fe / W-Ni-Cu
  точится и сверлится, M8 под потай — как в стали; цена заметно выше. Коррозия в стоках: W-Ni-Cu стойче, W-Ni-Fe — с покрытием.
- Решение за пользователем: вольфрам / свинец в капсуле / оставить сталь и принять WARN.
