## Кабель (открытый вопрос F23 закрыт)
По 752 C-C у D нет сквозной оси, только глухие резьбы на 8 мм с каждой стороны. Канал подъёма кабеля и литой
хвостовик идут в Y0: зазор до отверстий D по Y 10,8 мм. В плоскости XZ трасса проходит через проекцию D (−0,24 мм),
так что сквозная ось D дала бы пересечение. До оси C: 5,68 мм. Перекладывать трассу не понадобилось:
P X39,8 ≤ X41, радиусы R17 (неподвижные, ≥16,2) и R27 (подвижные, =5×D) прежние, запас длины 14,4 мм.
SP13 стоит соосно в посадке разъёма FSS-002-085, в 5,6 мм за передом кольца (у 752 3,65…5,4). Кабель выходит через
крышку FAL-002-081 на месте ввода M12 по 752 (+10 против +7,85).
