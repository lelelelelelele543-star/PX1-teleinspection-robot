## Тепловой расчёт (ESTIMATED, худший случай: сухая труба, воздух 40 °C, по допущениям F19)
- Прокладка: 0,0005 / (3 × 0,002095 м²) = 0,08 К/Вт, с контактом ≈0,12 К/Вт.
- Растекание в 7-мм Al крышке ≈0,1 К/Вт; крышка → корпус по опорному поясу 205×68 − 188×53 = 3976 мм² (DERIVED),
  h ≈ 1500 Вт/м²К → ≈0,17 К/Вт. Итого основание → стенка ≈0,4 К/Вт (в F19 было принято 0,3).
- Рабочая точка (46 Вт, потери 6,9 Вт): Tc ≈ 70 + 2,8 = **73 °C**. 120 Вт (потери 14,8 Вт, стенка ≈80 °C): Tc ≈ **86 °C**.
  150 Вт (18,5 Вт, стенка ≈84 °C): Tc ≈ **91 °C** ≤ 95 °C (расчётный предел), < 105 °C (макс.), OTP 110 °C.
  Было (модуль «в воздухе», Rca 10,1 К/Вт): ≈10 Вт выхода.
- Условие: крышка из алюминия (материал L01 пока HOLD — теперь обязательно Al), посадка крышки на корпус металл-металл.
