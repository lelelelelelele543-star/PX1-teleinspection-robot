# 08 PROCUREMENT

Procurement is stage-driven.

Buy first only what is required for A0/A1/A2:
- two traction motors matching the selected mount;
- matched bevel gears/shaft hardware;
- Z50 gears or fabrication material;
- bearings/bushings/seals for one complete crawler;
- six wheel samples/approved wheel solution;
- MCU + two traction drivers + RS-485 + DC/DC/protection;
- enough six-core tether for the 40 m prototype plus termination allowance.

Camera/reel/production cosmetics are second wave unless needed to unblock interface dimensions.

Every ordered item must be entered in `../PX1_Current_BOM.csv` with exact article, quantity, dimensions/source and its release/HOLD state.
