# A0 traction procurement shortlist

Only items needed to close the next physical gate are listed here.

## Use / source first
- 2 x FAULHABER 2250S024BX4 + 26/1 S 66:1 assemblies if available from existing stock.
- 2 x 61801-2RS (12x21x5) for Z16 support.
- 10 x 6001-2RS (12x28x8) for the disposable A0 five-gear fixture, or 5 x if one side is tested then reused.
- 5 x printed `PX1_A0_Z50_m1_PA20_TEST.stl` for A0.1, reuse for mirrored side; print 10 only if both sides are assembled simultaneously.
- 2 x printable `PX1_A0_SideFixturePlate_*.stl`.
- 5 x straight Ø12 mm temporary shafts for A0.1.

## Do not bulk-buy yet
- production Z50 gears: source bore/hub/heat treatment remains H04;
- Z16/Z40 bevel gears: full-load pair must have verified torque/material/heat treatment;
- TMCM-1640 x2: technically selected driver candidate but allowed-seller availability/price is still a procurement gate;
- final motor holder: wait for A0 motor/shaft fit;
- final crawler body/side covers: wait for A0 and H02/H03 closure.

## Fastest build order
1. Print fixture plates + five Z50 test gears.
2. Assemble five-gear hand-turn fixture.
3. Bench-run the two source-match motor/gearhead assemblies separately.
4. Make only the temporary 5 mm-to-12 mm pinion adapters.
5. Install actual suitable bevel pair and join motor module to the five-gear fixture.
6. Record A0 test sheet before any pressure-body machining order.
