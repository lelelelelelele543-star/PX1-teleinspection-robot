# 05 TETHER + REEL

Main tether architecture is frozen: professional reinforced six-core copper inspection cable, no coax in the main tether, field-reterminable, tensile load carried mechanically rather than by contacts.

Fast-track:
- first system length: 40 m;
- qualify conductor resistance, loaded voltage drop, RS-485 and video behaviour before 100–150 m design;
- temporary/manual cable handling is acceptable for A4 if safe and reliable.

RMP300-style reel, levelwind, brake, measuring wheel and slip ring are retained as the production direction but may not block first crawler demonstration.
