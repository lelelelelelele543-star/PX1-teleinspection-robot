# PX1 Current

Единственный текущий комплект. Механический эталон Proteus CRP-150; собственная электроника на готовых платах. Статус: **HOLD / не для изготовления**.

- CAD/PX1_Current_Master.py — единственный исходник сборки.
- CAD/PX1_Current_Master.step — экспорт после успешной сборки.
- PX1_Current_BOM.csv — единая BOM,127 строк, разделитель «;».
- PX1_Current_Validation.json — действительная проверка данного экспорта; не переносить старые результаты.
- PX1_Change_Log.md — единый журнал.
- SOURCE_REGISTER.md — источники размеров и границы достоверности.
- ELECTRICAL_Current.md — схемные соединения и логические распиновки.
- ASSEMBLY_AND_TESTS_Current.md — герметизация, давление, сборка, обслуживание, испытания.
- PX1_Drawings_Current.pdf / PX1_Documentation_Current.pdf — после успешного экспорта.

Metal_HOLD содержит CAD деталей для проверки, а не производственные чертежи. Print_STL содержит четыре примерочных макета. Полное изготовление металла, камера, посадка моторов, DN150 и давление не выпущены.

Сборка выполняется GitHub Actions «PX1 current export». Успех программы не означает инженерный PASS. Проверяйте SHA исходника в validation. Исторические WB и RevB не являются действующим master.
