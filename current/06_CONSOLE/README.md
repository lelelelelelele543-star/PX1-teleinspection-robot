# 06 OPERATOR CONSOLE

Purpose: portable first-working control unit.

Minimum A4 controls/display:
- 7-inch CVBS monitor;
- two-axis drive joystick;
- speed control;
- lighting control;
- crawler enable/stop;
- pressure indication;
- link/fault indication.

Distance, time, address and polished OSD remain planned but must not delay first drive/video demonstration unless already trivial to integrate.
