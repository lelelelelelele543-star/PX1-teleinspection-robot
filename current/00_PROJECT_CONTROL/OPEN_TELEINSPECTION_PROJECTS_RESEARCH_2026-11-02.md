# PX1 — поиск готовых открытых проектов телеинспекции труб
Дата первичного обзора: 2026-11-02
Статус: **RESEARCH / NOT A PRODUCTION RELEASE**

## Цель
Найти **реально скачиваемую и воспроизводимую** существующую систему/подсистемы канализационной телеинспекции: механика (CAD STEP/FreeCAD/SolidWorks), электроника/схемы, прошивка, камера, шестижильный кабель, катушка, пульт. Предпочтение — минимум собственной разработки, готовые покупные модули в РФ, повторяемость для 2–3 комплексов.

### Неприкосновенный PX1 baseline
- Близость к Mini-Cam Proteus CRP-150: **6 колес / 3 оси на борт, два двигателя, зубчатый привод Z16→Z40→5×Z50 на сторону**, не 6 отдельных моторов.
- Проход DN150, ручной лифт, отдельная герметичная CAM026-подобная голова, герметичный корпус с избыточным давлением, сменные уплотнения.
- 40 м на первом прототипе → 100–150 м; **единый усиленный медный шестижильный tether**, без коаксиала, оптики и обычных отдельных витых пар.
- Ручная катушка с укладчиком и счётчиком, отдельный пульт с видео/OSD; электроника PX1 собственная из покупных плат.
- Сначала решить доказанный blocker: `current/01_MECHANICAL_6X6/A15_MOTOR_FIT_BLOCKER.md` — Ø25×54 моторы пересекают A1.5 опорные пластины на 3,5 мм.

## Вывод по первому проходу
Полностью открытого **проверенного готового** комплекта «робот 6×6, CAM026-подобная голова, герметичный корпус, катушка, пульт, кабель и прошивки для DN150» пока **не найдено**. Наиболее полезные прямо сейчас — код STM32 и компактного ESP32-краулера; для механики промышленного PX1 по-прежнему лучше заводские чертежи Proteus, уже сохранённые пользователем на Google Drive. Не путать 3D-визуализацию с рабочей инженерной CAD-сборкой.

## Поручение исследовательскому агенту Codex / acceptance criteria
1. Продолжить точечный поиск по GitHub, GrabCAD, Onshape, FreeCAD community, Zenodo, китайским Gitee/CSDN/патентным базам, университетским архивам. Языки: RU/EN/CN. Не собирать очередные красивые рендеры.
2. Для каждого кандидата записать **прямую ссылку, лицензию/права, размер трубы, конфигурацию приводов, реальный список доступных файлов**, статус evidence: VERIFIED_FILES / DOC_ONLY / VISUAL_ONLY / UNVERIFIED.
3. **Скачать разрешённые открытые** сборки, составить inventory `STEP/STL/FCStd/SLDASM`, схемы `PDF/KiCad`, firmware/CI, BOM и инструкции; сохранить исходные URL и SHA256, отдельно от наших собственных CAD. Не загружать чужие проприетарные чертежи в публичный репозиторий.
4. Для 3 лучших механических кандидатов открыть CAD в FreeCAD или безопасно конвертировать, оценить реальные bounding boxes/число тел/коллизии/где моторы, наличие Z50 и DN150 clearance. Отделить реальные измерения от рендера.
5. Составить отдельную матрицу: crawler / camera pan-rotate / manual lift / tether video+power / reel / controller; указать «можно использовать без изменения / после адаптации / нельзя». Закупка только после проверки доступности и электрических параметров; по РФ — Чип-и-Дип/маркетплейсы.
6. Разобрать `A15_MOTOR_FIT_BLOCKER.md` прежде чем переносить чужую механику в наш мастер. **Не менять** шесть колёс, 2 мотора, зубчатую передачу и шестижильный кабель ради быстрого результата.
7. Выпустить отдельный воспроизводимый отчёт в `current/00_PROJECT_CONTROL/` с рейтингом TOP-5, прямыми ссылками, скриншотами оригинальных публичных CAD/фото (при разрешении), перечнем скачанных файлов, доказательной базой и планом интеграции. Выводить только проверяемые результаты. Никогда не заявлять manufacture/PASS без 3D- и стендовой проверки.

Исследование **не является** запуском локального Codex. Задачу можно передать работающему на ПК агенту либо запускать в существующем мультиагентном runner. Наличие записи в GitHub само по себе не означает автономное выполнение.
