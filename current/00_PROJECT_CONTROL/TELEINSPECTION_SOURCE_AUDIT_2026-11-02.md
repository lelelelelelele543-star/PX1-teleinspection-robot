# PX1: дополнительный аудит готовых проектов телеинспекции
Дата: 2026-11-02. Проверка внешних источников и публичных деревьев GitHub.
Назначение: конкретные проверенные заимствуемые **подсистемы**, а не замена базового Proteus CRP-150.
**Не является запуском Codex на ноутбуке, загрузкой внешних CAD или производственным разрешением.**

## Метод проверки
1. Внешний веб-поиск по EN/RU/CN: sewer inspection robot open-source firmware CAD STEP STL; GitHub, GrabCAD, Printables, китайские архивы и университетские публикации.
2. Для перечисленных GitHub-проектов получены метаданные default branch и рекурсивное **дерево файлов через GitHub connector**; наличие перечисленных файлов подтверждено, **содержимое бинарных CAD не проверялось**.
3. Верификация README и отдельных LICENSE проведена выборочно.
4. Статусы: **TREE_VERIFIED** — файл наблюдался в дереве; **PAGE_ONLY** — только карточка сайта; **UNVERIFIED** — прямые файлы/лицензия не проверены; **INCOMPATIBLE** — явно не под CRP150 и DN150.

## Пять наиболее применимых компонентов из найденного (не пять готовых систем)
1. STM32 HAL: энкодеры, давление, телеметрия — анализировать отдельно.
2. ArminJo: базовый контроллер двухбортового движения и обзор камерой — оценить пригодность кодовых паттернов.
3. PAAMB: проверить реальные STL для камеры (только для стенда).
4. waiyanminlu11: ПК-видеопоток/вывод дефектов, **только после решения кабеля PX1**.
5. Оригинальные DRW Proteus и имеющийся CAD-reconstruction PX1 по-прежнему **лучший источник механики**, т.к. открытые варианты не совместимы по геометрии/зубчатому приводу/герметизации.

## Обязательные действия перед переносом
- Не путать **«папка называется CAD»** с наличием CAD: проверять API tree и конкретные расширения.
- Полные CAD-файлы, доступные в публичных репозиториях, требуют проверки авторства и лицензии, включая вложенные чужие детали. Не публиковать в PX1 копии закрытых источников.
- Замерять все реальные модели в FreeCAD, строить swept collision DN150, проверять панорамную голову/подъёмник/хвостовой кабель.
- **HARD BLOCK:** `current/01_MECHANICAL_6X6/A15_MOTOR_FIT_BLOCKER.md` — пересечения Pololu #5707 Ø25×54 с пластинами A1.5 3.5 мм. Нельзя выпускать рабочий шасси из текущего STEP без переработки герметичного корпуса.
- Для новой электроники **отдельно доказать** долгую передачу видео и управление по 6-жильному усиленному кабелю на 40→150 м, ток, падение напряжения, EMC, заземление/защиту. Ни один найденный Wi-Fi/Ethernet rover не доказывает этого.
- Проверять COTS по Чип-и-Дип/маркетплейсам и не предлагать полную закупку до интерфейсных тестов.

## Промежуточный вывод
По состоянию на 2026-11-02 **полный открытый производственный аналог Proteus не найден**. Есть реальные источники ПО, STL держателей камеры и CAD **неподходящих** роботов. Экономия времени возможна главным образом на firmware/dashboard, **не на полной механике CRP150**. Следующий инженерный шаг: подтвердить интегрированную гермокомпоновку двух моторов в DN150, затем переходить к камере и кабельному стенду. Реального выполнения локальным Codex, проверки STEP в FreeCAD и физической сборки эта разведка не подтверждает.
