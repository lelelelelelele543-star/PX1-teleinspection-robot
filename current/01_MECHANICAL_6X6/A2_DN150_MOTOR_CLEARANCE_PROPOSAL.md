# PX1 A2 — независимая компоновка DN150 (версия 0.1, 14.11.2026)

**Результат:** параметрическая 3D-модель *габаритного исследования*, не выпуск рабочих чертежей. Снимает только старое номинальное столкновение двух мотор-редукторов с внутренними пластинами A1.5 **в новой предложенной архитектуре**: полый центральный корпус, боковые передачи снаружи сухой полости. Старый A1.5 не исправлен автоматически, это отдельная ветка конструкции.

## Конструкторские решения (PX1, не размеры Mini-Cam)

| Ширина колеса | 16 мм | собственный проектный размер |

| Ширина сборки по колёсам | 122 мм | вычислено; не габарит Proteus |
| Центр оси колеса от нижней точки круглой трубы | 66.367 мм | вычислен из геометрического касания внешнего угла протектора; для настоящих колёс необходимо скругление |

| Условная оболочка боковых шестерён | abs(Y)=33..45 мм | собственное предложение; надо сделать реальные подшипники/сальники/крышки |

**Подтверждённый внешний референс, не собственные размеры:** CPL150S 307 × 133 × 110 мм, назначение DN150–375, масса 9.25 кг, руководство Minicam Version L, стр.107: https://www.minicam.co.uk/wp-content/uploads/2022/04/Proteus_Version-L_EN-2022-RL.pdf . Более раннее руководство использует другие размеры CRP150; версии нельзя смешивать.

## Что проверено автоматически

- два цилиндра редукторов Ø26 на осях Y±13.5: 1.0 мм номинального зазора друг от друга;
- край редукторов ±26.5: 1.5 мм до внутреннего лица стенки на Y±28;
- внешний профиль прямоугольного протектора Ø70 ×16 мм при Y=45..61 математически касается круга DN150 — нет проникновения при идеальных параметрах;
- 6 колёс, 10 символических m1/Z50 шестерён (пять на сторону), два мотора;
- отрицательные тесты обнаруживают слишком большой редуктор, слишком широкую шину и неправильный шаг шестерён.

**Не проверено:** реальный внутренний диаметр конкретной трубы и грязевые зазоры; контакт и сцепление покрышек (прямоугольная шина касанием угла не работает как готовая промышленная шина); механический корпус, крышки, 0.4–0.7 bar, уплотнения, bearing arrangement, коническая передача Z16/Z40, технологичность, кабель/хвост, лифт, камера, фактическая электродинамика, нагрузки на шестерни и прочность. **Не отправлять эту сборку на изготовление**; применять как геометрическую базу для последующих деталей.

## Воспроизведение

```bash
python PX1_A2_Envelope.py --out PX1_A2_outputs
python -m unittest -v test_px1_a2.py
# Для настоящего габаритного STEP нужен cadquery с OCC:
python PX1_A2_Envelope.py --out PX1_A2_outputs --cad
```

`PX1_A2_Orthographic.svg` — векторная эскизная 2D-схема; `PX1_A2_Envelope_Assembly.step` — 3D **габаритные тела**, не реальные зубья/посадочные места. Сухой корпус на STEP визуализирован как полая оболочка. Не использовать как seal-rated pressure vessel.

## Следующий шаг (самостоятельно)

Сделать детальный 3D узел заднего ведущего вала и двух радиальных подшипников на сторону, с точным осевым переходом из сухого корпуса в мокрый боковой редуктор и с проверкой коллизии Ø70 шин; затем выбрать промышленные подшипники и сальники по действующим каталогам, а не по аналогии из головы.
