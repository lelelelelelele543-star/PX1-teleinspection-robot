# A56 — 3D conical tooth loft proxy
This stage advances from flat virtual tooth profiles to **ruled 3D tooth solids**. It does not claim correct bevel gear meshing. The FreeCAD script produces individual compound tooth solids for Z16 and Z40, not a positioned 90° transmission. No bearing, hub, root fillet, backlash, contact stress, torque capacity, or 3D interference is verified.
The SVG preview is generated from the **same numeric parameters** but depicts the outer tooth-sector projection and inner pitch radius only. It is not a FreeCAD render.
Inputs: module 1.5 mm, 16/40 teeth, face width 8 mm, cone distance 32.310989 mm. All unverified geometry is ESTIMATED/PROXY.
**Next:** correct physical 90° axis placements; generate conjugate bevel teeth using validated gear method; test interference and bearing envelope. FreeCAD script has not been executed in this environment; STEP and FCStd are expected outputs, not claimed deliverables.
