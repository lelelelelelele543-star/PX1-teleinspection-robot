# PX-1 Rev.AU — rear shaft end / wheel retention freeze

Status: DRAWING-CANDIDATE, pending exact supplier part confirmation and physical mock-up.

## Rear shaft end
- shaft main diameter: Ø10 mm
- seal journal: Ø10 h6, Ra <=0.4 µm
- bearing journal: Ø10 h6
- external threaded end: M8x1.25
- threaded length target: 12 mm
- thread starts only outside seal/bearing working zones
- transition Ø10 -> M8 uses a relief/undercut so wheel/washer can seat fully
- shaft keyway for wheel/gear: 3x3 mm, external zone only

## Wheel retention stack
From inside to outside:
1. removable gear / hub zone
2. wheel hub 18 mm
3. ISO 7089 M8 flat washer, nominal 8.4x16x1.6 mm
4. M8 prevailing-torque lock nut, 13 mm wrench size target

The M8 lock nut is selected as the prototype retention method because it is simple, cheap, available and replaceable in the field.

## Preferred nut class
Preferred: stainless A4 M8 nylon-insert or all-metal prevailing-torque lock nut from a reputable industrial supplier.

ChipDip documentation confirms M8 DIN 985 geometry with 13 mm wrench size and approximately 8 mm maximum height for the referenced Bossard type. Exact ChipDip stock/order code still must be verified at purchase time.

## Service envelope
- minimum socket envelope around M8 nut axis: Ø20 mm
- straight socket approach required
- no side-cover fastener may block the socket
