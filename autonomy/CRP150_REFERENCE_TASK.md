# PX1 — автономная задача: реконструкция CRP150 + CAM026

## Цель
По заводским чертежам, доступным фотографиям, видео и инженерным расчётам создать ДВЕ раздельные эталонные CAD-модели CRP150_REFERENCE и CAM026_REFERENCE, затем их общую проверенную сборку. Не подменять их PX1_ADAPTED и не перепроектировать робота до окончания реконструкции. Пользователя не просить измерять оригинал.

## Правила
Прочитать AGENTS.md, current/README.md, current/SOURCE_REGISTER.md, reference/Proteus-CRP-150/ и autonomy/CRP150_REFERENCE_PROGRESS.md. Не путать исторические Rev с текущими решениями. Использовать имеющиеся закрытые заводские чертежи только локально; не выкладывать их в публичный GitHub. Не утверждать, что неоткрытые чертежи или ролики проверены.

## Последовательность конкретной инженерной работы
1. Создать SOURCES.md с URL или путём, названием, датой, моделью/исполнением, ракурсом, известным размером и уровнем надёжности.
2. Создать DIMENSION_REGISTER.md: OFFICIAL / CROSS_CONFIRMED / DERIVED / ESTIMATED / SOURCE_CONFLICT / UNKNOWN, с вычислениями и погрешностью.
3. Построить CRP150_REFERENCE: корпус, 6 колёс, по пять m1 Z50 на борт, станции X50/X150/X250, две Z16→Z40 конические передачи, задний приводной X250, опоры валов, крышки, уплотнения, хвост, ручной подъёмник. Форма только по источникам; неопределённые части маркировать.
4. Построить отдельно CAM026_REFERENCE: подтвердить вариант камеры, геометрию, оси PAN/ROTATE, отдельное уплотнение, положения и движения. Не придумывать OEM-внутренности.
5. Собрать CRP150+CAM026, проверить LOW/MID/HIGH, кинематику, DN150, пересечения, сборку и обслуживание.
6. Сделать сопоставление FRONT/REAR/LEFT/RIGHT/TOP/BOTTOM/3-4 CAD с реальными фото/видео: наложения, воспроизводимые параметры вида, карту ошибок; последовательно исправлять несовпадения.
7. Выпустить параметрические исходники, проверяемый STEP и FreeCAD FCStd (если установлен FreeCAD), подробный README, скрипты/журнал проверок, список незакрытых отклонений. CAD-экспорт сам по себе не является PASS.

## Ближайший обязательный результат (первый цикл)
Реальный инвентарь доступных источников и CAD, исходные регистры размеров/доказательств и первая запускаемая CAD-реконструкция корпуса и шестиколёсной схемы CRP150 со сверкой FRONT/SIDE/TOP. Не заканчивать одним текстовым планом.

## Правило непрерывности
После КАЖДОГО рабочего цикла обновлять autonomy/CRP150_REFERENCE_PROGRESS.md: что физически записано в файлы, какие команды/проверки реально выполнены, что ещё не совпадает, следующий исполнимый шаг. STATUS: IN_PROGRESS до подтверждения ВСЕХ критериев 1–7. STATUS: COMPLETE допускается только при наличии проверяемых результатов и явной карте оставшихся неопределённостей; это завершённая реконструкция, а не подтверждение готовности PX1 к продаже.

Не останавливаться только из-за отсутствующего заводского размера: реконструировать с пометкой оценки и погрешности. При недоступности сети или FreeCAD продолжать доступные независимые подзадачи. Не менять current/, не устанавливать программы, не выполнять покупки, публикации, git push и опасные действия без разрешения.
