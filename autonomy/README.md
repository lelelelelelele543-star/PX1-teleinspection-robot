# Автономный PX1: локальный Codex

Это локальный повторяемый агент для реконструкции CRP150, а не обещание фоновой работы из обычного мобильного чата. После ОДНОГО запуска на ПК агент выполняет ограниченное число независимых циклов, сохраняет контрольную точку и читает её в следующем цикле. Для продолжения после выключения или сбоя можно снова запустить ту же команду.

## Запуск на Windows (PowerShell)
1. Открыть локальную копию репозитория lelelelelelele543-star/PX1-teleinspection-robot и выполнить git pull.
2. Должны работать Python 3, Git и Codex CLI. При необходимости установить Codex командой npm install -g @openai/codex, войти через codex login. Проверить codex --version.
3. Из корня репозитория: py -3 tools/px1_autorun.py --dry-run
4. Запуск: py -3 tools/px1_autorun.py --cycles 8

На Linux/macOS: python3 tools/px1_autorun.py --cycles 8.

Для каждого цикла используется безопаснее ограниченный режим --sandbox workspace-write, без индивидуальных запросов разрешений для работы внутри проекта; это НЕ полный контроль над компьютером. Среда может не разрешать браузер или запуск графического FreeCAD. Для работы с GUI/браузером можно открыть локальный репозиторий в ChatGPT Desktop Work/Codex и дать разрешения.

Прогресс: autonomy/CRP150_REFERENCE_PROGRESS.md
Задание: autonomy/CRP150_REFERENCE_TASK.md
Логи на ПК: .px1-agent/runs/ (не отправляются в Git).
Результаты: reference/Proteus-CRP-150/cad/reconstruction/

Программа сама НЕ отправляет коммиты на сервер, НЕ покупает детали, НЕ устанавливает ПО и НЕ меняет current/. Ограничение по умолчанию — 6 циклов до 1 часа; после 2 подряд ошибокных запусков она остановится с логом. Поэтому гарантировать бесконечную бесконтрольную работу нельзя; смысл — не терять результат и возобновлять задачу без повторных объяснений.
