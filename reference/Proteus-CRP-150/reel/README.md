# RMP300 reel reference work area

The replacement will preserve:

- manual drum;
- 160 mm crank handle;
- mechanical brake;
- mechanical level wind;
- 272 mm level-wind spindle reference;
- measuring wheel and replaceable encoder;
- serviceable slip ring in the main shaft path;
- lightweight portable frame.

The reel drive motor and proprietary counter PCB are not part of the prototype baseline.
