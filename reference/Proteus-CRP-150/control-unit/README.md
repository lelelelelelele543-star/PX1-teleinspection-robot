# Proteus-style control-unit reference work area

Target operator functions:

- crawler forward/reverse and left/right differential steering;
- speed control;
- camera PAN and ROTATE control;
- lighting control;
- distance, pressure, time and address display;
- 7-inch video monitor;
- RS-485 commands and telemetry;
- modular replaceable electronics.

Prototype baseline: 24 V distribution, STM32 NUCLEO-F446RE, two BTS7960 traction drivers, external OSD and no custom main PCB.
